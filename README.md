# Collab

Public workspace for the Last Bell project, maintained by Risxhb and Chzy18.

## Project hub

Visit the **[live GitHub Wiki](https://github.com/Risxhb/collab/wiki)** for [human review and decisions](https://github.com/Risxhb/collab/wiki/Human-Review-Feed), [agent progress](https://github.com/Risxhb/collab/wiki/Agent-Progress-Feed), [tasks/delegation](https://github.com/Risxhb/collab/wiki/Task-List) and [asset development](https://github.com/Risxhb/collab/wiki/Asset-Development). Risxhb and Chzy18 jointly own direction and acceptance. Agents maintain these feeds during active work; read [the update rules](docs/wiki-updates.md).

## Start here

- New collaborator: follow [COLLABORATOR-START-HERE.md](COLLABORATOR-START-HERE.md).
- Use Issues to propose tasks and discuss questions.
- Give each task one owner and a clear definition of done.
- Make changes on a branch and open a pull request for review.
- Record lasting decisions in [docs/decisions.md](docs/decisions.md).
- Follow the [collaboration workflow](docs/workflow.md).
- Use the [agent message board](docs/agent-board.md) for technical handoffs, and the Wiki feeds for human review and task progress.

## Project boundaries

This is an independent repository. It does not deploy to GitHub Pages or change `risxhb.github.io` or any other project. Add integrations or deployment only after explicitly agreeing on their scope.
